Factory Inventory Management System

A demo full-stack app: Vue 3 single-page frontend, FastAPI backend, and in-memory JSON mock data. There is no database.

System architecture

Tech stack

Frontend

  • Vue 3 (Options-style setup() with Composition API)
  • Vite 8 dev server and build
  • vue-router 4, axios
  • Custom SVG charts, CSS Grid layouts
  • English and Japanese locales

Backend

  • Python 3.11+, FastAPI, uvicorn
  • Pydantic 2 models
  • Managed with uv
  • No database, no auth

Tooling

  • pytest + FastAPI TestClient (67 backend tests)
  • scripts/start.sh and stop.sh
  • Claude Code agents, skills, and MCP (GitHub, Playwright) under .claude/
  • No linting or frontend tests

Data flow

  1. A user changes a filter (period, warehouse, category, status). State lives in module-level refs in useFilters.js, so all views see it.
  2. getCurrentFilters() maps UI names to API params (selectedLocation to warehouse, selectedPeriod to month).
  3. A view calls a method on api.js, which drops any param equal to 'all' and sends GET /api/....
  4. FastAPI runs apply_filters() and filter_by_month() over in-memory lists. month accepts YYYY-MM or Q1-2025 to Q4-2025.
  5. Pydantic validates the response, and the JSON returns to the browser.
  6. The view stores raw data in refs. Computed properties derive totals, chart series, and status counts, and Vue re-renders.

Things worth knowing

  • api.js and App.vue call /api/tasks and /api/purchase-orders, but the backend defines no such routes, so those calls return 404. CreatePurchaseOrderRequest in main.py is unused.
  • The only write path is POST /api/restock-orders. Submitted orders live in a module-level list and reset when the server restarts. Prices come from server/data/restock_catalog.json because inventory.json covers only one forecast SKU.
  • views/Backlog.vue exists but is not registered in the router.
  • Sample data is small: 250 orders, 32 inventory items, 4 backlog items, all dated 2025. server/generate_data.py regenerates it.
  • The API base URL is hardcoded in api.js and Reports.vue.
